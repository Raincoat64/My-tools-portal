# 高圧ガス手続きナビ（奈良県向け）

事業者が、必要な手続き、公式様式・記載例、添付書類、提出時期・方法を確認するための参考ツールです。県の公式サイトではありません。申請の送信や設備の適合性の審査は行いません。

## 利用する

- `../../tools/kouatsu-gas-law-viewer.html` をブラウザーで直接開きます。
- 開発時はプロジェクトをHTTPサーバーで配信し、`index.html` を開きます。リポジトリ直下で `python -m http.server 8420` を実行し、`/src/kouatsu/` または `/tools/kouatsu-gas-law-viewer.html` を開きます。
- 固定の案内・質問は単体版ならオフラインでも利用できます。公式様式の取得・e-Gov条文の新規取得にはインターネット接続が必要です。
- 回答・書類チェック・履歴は、この端末・このブラウザー内のIndexedDBにのみ保存します。別端末・別ブラウザー・ローカルファイルとは自動共有しません。同じHTTPS origin上の本ツールは保存領域を共有します。保存できない環境でも案内は利用できます。
- 「印刷・PDF保存」から申請準備一覧と回答を保存できます。チェックは準備メモであり、申請書類の内容を検証するものではありません。

## 対応範囲

一般則・液石則・冷凍則の製造、貯蔵、販売、消費の新規手続きと、変更・軽微変更・県規則の報告・承継・廃止・製造施設の休止・検査・製造開始・保安担当者・危害予防規程を案内します。条文閲覧は容器則にも対応します。

変更工事は、現在の第一種／第二種、工事内容、軽微変更の具体的要件を質問します。条件が不足する場合は候補を表示し、「不要」とは断定しません。事前連絡・検査日程調整が県から求められる場面は、その工程と準備資料を示します。

次は自動確定の対象外です。

- コンビナート則、認定事業者の特別な取扱い、設備設計・技術基準の完全な適合判定。
- 未確認のガス分類、特殊な貯蔵の組合せ、複合工事、役職のすべての選任免除。
- LP法自体の診断・申請。該当時は県のLP法案内を開けます。
- 施設ごとに異なる追加資料、許可・検査手数料の自動計算。手数料は奈良県条例の区分と金額を事前連絡時に確定してください。県ページにある不明瞭な金額表記を推測して転載していません。

## 構成と保守

- `js/diagnosis.js`：四行為の新規区分判定。根拠監査は `docs/diagnosis-audit.md`。
- `js/procedures.js`：手続き台帳、公式ファイル、書類の条件、変更等の質問・分岐。`procedureId` は保存・検索・結果の共通識別子です。
- `js/procedureView.js`：共通の申請準備表示。必須／条件付き／いずれかを区別します。
- `js/main.js`：画面遷移、診断、検索、回答修正、保存復元、条文閲覧。
- `js/storage.js`：既存キャッシュ・履歴を保持したままDBをv2にし、下書き用ストアを追加します。
- `index.html` と `css/style.css`：通常版と単体版に共通の画面ソース。

法令改正・県の様式更新時は出典を照合し、台帳と診断を修正して `PROCEDURE_VERSION` を更新します。旧版の下書き・履歴はそのまま現在の判定として使用せず、再回答を求めます。`PROCEDURE_CHECKED_AT` は案内・条件の確認日であり、e-Govの条文取得日とは別です。API取得のみで診断が自動更新されることはありません。

### 単体版生成

リポジトリ直下でPython 3.9以上を使って実行します（古い `py` の既定バージョンに注意）。

```text
python scripts/build_kouatsu.py
```

`index.html` の画面本体とCSS・JSを埋め込みます。単体版を手作業で編集しないでください。モジュールを追加するときはビルドスクリプトの依存順リストも更新します。

### 検証

Node.js 24で確認済みです。

```text
node --test tests/kouatsu-*.test.mjs
```

ブラウザー検証には、検証環境側のPlaywrightとChromium系ブラウザーを使用します。アプリ本体への依存追加は不要です。

```text
node tests/kouatsu-browser-smoke.mjs
```

既定のPlaywright／ブラウザーがない場合、`NAV_PLAYWRIGHT_PATH` にPlaywrightパッケージのパス、`NAV_BROWSER_PATH` にEdge等の実行ファイルのパスを指定します。テストは一時ブラウザープロファイルとループバックサーバーで実行し、通常の閲覧プロファイルの履歴や保存内容を変更しません。

## GitHub Pagesでの利用・更新

公開先は https://raincoat64.github.io/My-tools-portal/tools/kouatsu-gas-law-viewer.html です。ポータルの高圧ガスカードから開けます。iPhoneはSafariの共有メニュー、AndroidはChromeのメニューからポータルをホーム画面へ追加できます。

今回の更新は旧「手続き・基準ナビv2」との機能統合ではなく、奈良県向け版への差し替えです。旧版の`kouatsu-navigator-history`（localStorage）と`kouatsu-navigator-laws`（IndexedDB）は変換・削除しません。旧履歴がある場合は再回答を案内します。PCのローカルHTMLとスマホの保存内容も自動共有しません。

公開HTMLはこのディレクトリから生成します。`python scripts/build_kouatsu.py --check`で生成一致を確認し、ポータルのService Workerのシェルキャッシュ版も更新してPRから反映してください。Pages設定はmain/rootとHTTPSを維持します。Service Workerは自分のscopeのシェルだけを世代更新し、他のツールのランタイムキャッシュと保存データを削除しません。

公開前に診断・台帳、配布HTML、`node tests/kouatsu-pages-smoke.mjs`でサブパス・旧SWからの更新・オフライン動作を確認します。後者も同じPlaywright／ブラウザー環境変数を使用します。公開後はPagesの成功commitと配布HTMLのSHA-256を照合してください。問題時はこの更新のコミットをrevertして再公開できます。
