# 高圧ガス 手続き・基準ナビ v2

配布ファイルは `tools/kouatsu-gas-law-viewer.html`。HTML・CSS・JavaScript・確認済みの一部条文を1ファイルに内包し、利用者側のインストールは不要です。

## 生成・検証

リポジトリのルートで実行します。実行時依存・npmパッケージはありません。

```sh
python3 scripts/build_kouatsu.py
node --test tests/kouatsu.test.cjs
```

配布HTMLは生成物です。画面の外殻も含めてこのディレクトリを正本として生成し、配布版に手書きで変更を積み重ねないでください。

| ファイル | 内容 |
| --- | --- |
| template.html / style.css | 画面の外殻・レスポンシブ表示・印刷 |
| data.js | 手続カタログ、出典、県書類一覧、技術テーマ |
| engine.js | 条件付き書類、冷凍設備変更、不明状態、期限計算 |
| classification.js | 既存の製造・貯蔵・消費・販売の区分算定を継承 |
| laws.js | e-Gov API、保存失敗時の代替動作、原文表示、版照合 |
| snapshots.json | 2026-09-05取得のe-Gov法令原文のうち収録対象条文 |
| app.js | 3つの入口と共通詳細画面、履歴、印刷 |

## 対象範囲

- 冷凍の第二種製造届：法令上の書類・記載事項、認定指定設備、移設等、明細書の省略条件。
- 冷凍の第一種・第二種製造施設の変更：通常の取替え、独立設備の撤去、製造設備以外の取替え、認定指定設備の設置・変更。
- 複合工事は項目単位で評価。未確認の項目が残る場合は案件全体を届出不要にしません。
- 法令原文は法律、施行令、一般則、液石則、冷凍則、容器則。保存版は一部条文のみ。e-Govから現在の全文を取得すると、本則の検索及び附則・別表・様式等も表示できます。
- その他の手続きは公式資料に案内。例示基準は経済産業省の掲載ページへの動線を維持し、PDFごとの現行ページ・項目索引は未収録です。
- 既存の区分算定は適用確認・特別条件・不明回答の入口を追加して継承。全ての法的例外を自動判定するものではありません。

## 既存版からの修正

- 冷凍第二種製造届の期限を製造開始の20日前と明示。
- 第一種の危害予防規程・保安教育計画を第二種へ一括表示する旧チェックリストを廃止し、法第27条第4項の保安教育義務と分離。
- 既存の「自家消費＝事業ではない」という設問表現、販売免除に第一種製造者であることを確認しない表現、業務用LPガスを一律に液石法対象外とする表現を修正。
- 照会履歴を常設欄からダイアログに移し、主画面を広く使用。
- 履歴の保存は利用者操作。法令の保存失敗でも本体を停止しません。
- 現行のポータル用サービスワーカーのキャッシュ版を更新。ツール単体はサービスワーカーに依存しません。

今回の重点的な条文照合は法第5条・第14条・第20条・第26条・第27条、冷凍則第3条・第4条・第16〜19条・第23条・第35条・第36条・第44条・第62条です。原文データの取得は全収録条文の法的判断をレビュー済みという意味ではありません。

例示基準の掲載ページ本文の取得は403となったため、新しいPDFページ対応を推測して実装していません。

## 更新時の注意

法令本文と判定ルールは別物です。全文取得時には `law_revision_id` と `current_revision_status` を照合し、案内の確認済み版と違う場合は画面へ表示します。通信失敗時は保存版を残します。版一致は例示基準・県資料も更新確認済みという意味ではありません。

1. e-Govの原文・施行日・改正ID、関係する告示・通達・附則を確認する。
2. 影響する手続き、例外、書類要否を確認して `data.js` / `engine.js` を更新する。
3. 関係条項のスナップショット及び確認日・バージョンを更新する。取得した原文は改変しない。
4. 条件の境界・不明回答・例外の検証を行い、単一HTMLを再生成する。
5. 新版のHTMLを再配布する。配布済みのローカルHTMLは自動的には置き換わらない。

現在は地域の提出案内を全国共通／奈良県に分離しています。別地域の部数・窓口等を追加する際は出典を別データとして持たせてください。
