# 高圧ガス手続きナビ（奈良県向け）

事業者が、必要な手続き、公式様式・記載例、添付書類、提出時期・方法を確認するための参考ツールです。県の公式サイトではありません。申請の送信や設備の適合性の審査は行いません。

## 利用する

- `../../tools/kouatsu-gas-law-viewer.html` をブラウザーで直接開きます。
- 開発時はプロジェクトをHTTPサーバーで配信し、`index.html` を開きます。リポジトリ直下で `python -m http.server 8420` を実行し、`/src/kouatsu/` または `/tools/kouatsu-gas-law-viewer.html` を開きます。
- 固定の案内・質問は単体版ならオフラインでも利用できます。公式様式の取得・e-Gov条文の新規取得にはインターネット接続が必要です。
- 回答・書類チェック・履歴は、この端末・このブラウザー内のIndexedDBにのみ保存します。履歴は書込時に直近200件、書類チェックは直近50案件に整理します。上限を超えた古い分は削除されるため、必要な結果は印刷・PDF保存してください。同一案件の複数手続きはまとめて保持し、条文キャッシュや旧版データは整理対象にしません。別端末・別ブラウザー・ローカルファイルとは自動共有しません。同じHTTPS origin上の本ツールは保存領域を共有します。保存できない環境でも案内は利用できます。
- 「印刷・PDF保存」から申請準備一覧と回答を保存できます。チェックは準備メモであり、申請書類の内容を検証するものではありません。

## 改正情報・回答補助・持ち運び

- 起動時にe-Govの7法令の改正一覧を照合します。確認後の施行済み改正・未確認の施行予定改正があれば、ホーム・診断結果・手続き詳細の上部に注意を出します。判定や台帳を自動更新する機能ではありません。
- 確認済みの2026年12月21日施行予定改正は出典欄の注記です。注意と注記は印刷にも含めます。取得できない場合は出典欄に「改正の有無を確認できませんでした」と表示し、案内は継続できます。
- 照合の成功・失敗の結果を24時間、既存lawCacheの予約キー __revision-check__ に保持します。失敗を含め、その間の起動では再取得しません。法令本文のキャッシュや他ツールのデータは削除しません。
- 「答えが分からないとき」から関連用語と、対象設問の計算補助を開けます。貯蔵・消費の貯蔵能力、法定冷凍能力に対応。処理能力は計算せず、書類の記載値を案内します。対象外設備・冷媒はメーカー資料等の記載値を使用してください。
- 計算結果は小数第2位まで表示しますが、区分判定と回答への適用は丸め前の値を使います。「この選択肢を選ぶ」を押すまでは回答を変更しません。複数設備を足す場合は、設問が求めるガス区分・同じ対象施設の設備だけを入力してください。
- 「回答を共有・持ち運ぶ」でURLを作れます。URLのフラグメントに検証可能な選択肢・数値回答と画面位置を含め、書類チェックは含めません。フラグメントはサーバーへ送信しません。標準のdeflate-raw圧縮に未対応なら非圧縮とし、2,000文字を超える場合はJSON書き出しを案内します。
- JSONは回答と書類チェックを含みます。形式は kouatsu-navi / schemaVersion 1、ファイル名は kouatsu-navi-YYYYMMDD.json、読み込みは1MB以下です。未知の設問・選択肢・形式や、判定版が異なるデータは読み込まず再回答を案内します。
- URL・JSONとも検証後に確認画面を出します。既存の下書きがあれば、上書きか表示のみかを選びます。表示のみの間は回答・チェックを変更しても端末の下書きには保存しません。元の回答へ戻るときはホームの「続きから再開」を使います。
- fileの共有URLは、その端末の同じローカルパスを指します。異なる端末でパスが異なる場合はJSONで持ち運ぶか、公開版のURLを使ってください。ブラウザー間で保存領域が自動同期される機能ではありません。
- 新しい実行時通信は https://laws.e-gov.go.jp/api/2/law_revisions/{law_id} だけです。外部スクリプト・追加ライブラリはありません。コード移植は行っていません。

### 改正照合の基準値を更新する

1. 案内の対象法令と県の案内を再確認します。APIの取得成功だけで「確認済み」にしないでください。
2. js/revisions.js の REVISION_BASELINES（7法令のCurrentEnforced改正ID）を、再確認した版へ更新します。
3. 内容を確認したUnEnforced改正だけを KNOWN_PENDING_REVISIONS に追加・更新し、KNOWN_PENDING_INFO と KNOWN_REVISION_NOTE の施行日・法令名・注記も合わせます。施行済みになったものは基準値へ反映して予定から外します。
4. 案内の再確認時はPROCEDURE_CHECKED_ATを更新し、設問・判定に変更がある場合だけPROCEDURE_VERSIONも更新します。今回の回答補助追加では両方とも据え置いています。
5. 基準IDまたは既知予定IDの変更はキャッシュタグに反映され、古い照合キャッシュは使われなくなります。以下のテストと単体HTMLの再生成を行い、SWの世代も更新します。

実装モジュールは revisions.js（照合）、glossary.js（用語）、calculators.js（純粋計算）、assistView.js（補助表示）、portability.js（形式・復元前検証・符号化）に分離しています。


## 対応範囲

一般則・液石則・冷凍則の製造、貯蔵、販売、消費の新規手続きと、変更・軽微変更・県規則の報告・承継・廃止・製造施設の休止・検査・製造開始・保安担当者・危害予防規程を案内します。条文閲覧は容器則にも対応します。

変更工事は、現在の第一種／第二種、工事内容、軽微変更の具体的要件を質問します。条件が不足する場合は候補を表示し、「不要」とは断定しません。事前連絡・検査日程調整が県から求められる場面は、その工程と準備資料を示します。

次は自動確定の対象外です。

- コンビナート則、認定事業者の特別な取扱い、設備設計・技術基準の完全な適合判定。
- 未確認のガス分類、特殊な貯蔵の組合せ、複合工事、役職のすべての選任免除。
- LP法自体の診断・申請。該当時は県のLP法案内を開けます。
- 施設ごとに異なる追加資料、許可・検査手数料の自動計算。手数料は奈良県条例の区分と金額を事前連絡時に確定してください。県ページにある不明瞭な金額表記を推測して転載していません。

## 構成と保守

- `js/diagnosis.js`：四行為の新規区分判定。根拠監査は `docs/diagnosis-audit.md`。
- `js/procedures.js`：手続き台帳、公式ファイル、書類の条件、変更等の質問・分岐。`procedureId` は保存・検索・結果の共通識別子です。
- `js/procedureView.js`：共通の申請準備表示。必須／条件付き／いずれかを区別します。
- `js/main.js`：画面遷移、診断、検索、回答修正、保存復元、条文閲覧。
- `js/storage.js`：DB v2のストア構成を維持し、履歴・案件数の上限と一時的な接続失敗からの再試行を管理します。
- `index.html` と `css/style.css`：通常版と単体版に共通の画面ソース。

法令改正・県の様式更新時は出典を照合し、台帳と診断を修正して `PROCEDURE_VERSION` を更新します。旧版の下書き・履歴はそのまま現在の判定として使用せず、再回答を求めます。`PROCEDURE_CHECKED_AT` は案内・条件の確認日であり、e-Govの条文取得日とは別です。API取得のみで診断が自動更新されることはありません。

### 単体版生成

リポジトリ直下でPython 3.9以上を使って実行します（古い `py` の既定バージョンに注意）。

```text
python scripts/build_kouatsu.py
```

`index.html` の画面本体とCSS・JSを埋め込みます。単体版を手作業で編集しないでください。モジュールを追加するときはビルドスクリプトの依存順リストも更新します。

生成時と `--check` 時に、連結されるトップレベルの `function`・`async function`・`const`・`let`・`class` の重複を検査します。同名があれば名前と所在ファイルを表示して停止します。コメント・文字列・内部スコープの名前は対象外です。内部用ヘルパーにも衝突しない名前を付けてください。

### 検証

Node.js 24で確認済みです。

```text
node --test tests/kouatsu-*.test.mjs
python tests/kouatsu-build.test.py
python scripts/build_kouatsu.py --check
```

`kouatsu-citations.test.mjs` は診断・手続き一覧の引用リテラル全件を抽出し、先頭の条番号に対応する法令名と `lawId`、条番号（枝条を含む）と `num` を照合します。未抽出の引用も失敗とし、誤った法令IDを混ぜる負例を含みます。台帳の自由文 `basis` は対象外です。これは文言と参照の整合検査であり、現行法の再調査を代替しません。

`kouatsu-build.test.py` は各宣言種別の衝突、通常生成・照合の両経路での拒否、分割束縛と内部名の除外を確認します。製品ファイルには検査用の重複を書き込みません。

ブラウザー検証には、検証環境側のPlaywrightとChromium系ブラウザーを使用します。アプリ本体への依存追加は不要です。

```text
node tests/kouatsu-browser-smoke.mjs
node tests/kouatsu-business-assist-browser.mjs
```

既定のPlaywright／ブラウザーがない場合、`NAV_PLAYWRIGHT_PATH` にPlaywrightパッケージのパス、`NAV_BROWSER_PATH` にEdge等の実行ファイルのパスを指定します。テストは一時ブラウザープロファイルとループバックサーバーで実行し、通常の閲覧プロファイルの履歴や保存内容を変更しません。外部HTTPSは遮断し、APIの応答も模擬します。通常のESモジュール版・配布HTMLのHTTP版・直接開く単体版で、未確認結果と書類条件の復元、スマートフォン幅、200%拡大、印刷、読み上げ文、見出し階層、バナーのコントラスト比を確認します。保存上限は実IndexedDBでも検査します。

## GitHub Pagesでの利用・更新

公開先は https://raincoat64.github.io/My-tools-portal/tools/kouatsu-gas-law-viewer.html です。ポータルの高圧ガスカードから開けます。iPhoneはSafariの共有メニュー、AndroidはChromeのメニューからポータルをホーム画面へ追加できます。

今回の更新は旧「手続き・基準ナビv2」との機能統合ではなく、奈良県向け版への差し替えです。旧版の`kouatsu-navigator-history`（localStorage）と`kouatsu-navigator-laws`（IndexedDB）は変換・削除しません。旧履歴がある場合は再回答を案内します。PCのローカルHTMLとスマホの保存内容も自動共有しません。

公開HTMLはこのディレクトリから生成します。`python scripts/build_kouatsu.py --check`で生成一致を確認し、ポータルのService Workerのシェルキャッシュ版も更新してPRから反映してください。Pages設定はmain/rootとHTTPSを維持します。Service Workerは自分のscopeのシェルだけを世代更新し、他のツールのランタイムキャッシュと保存データを削除しません。

公開前に診断・台帳、配布HTML、`node tests/kouatsu-pages-smoke.mjs`でサブパス・旧SWからの更新・オフライン動作を確認します。後者も同じPlaywright／ブラウザー環境変数を使用します。公開後はPagesの成功commitと配布HTMLのSHA-256を照合してください。問題時はこの更新のコミットをrevertして再公開できます。
