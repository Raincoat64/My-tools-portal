## 監査結果と実装

### 1. 製造

- 一般則は第一種ガスのみ300m³/日、第一種ガス以外のみ100m³/日、混合は一般則第102条の `T = 100 + (2/3) × S1` で許可境界を判定する既存条件を維持した。
- 液石則の製造許可境界100m³/日と、境界未満で事業として反復・継続する場合の第二種製造届出を維持した。
- 液石則の製造では `lpgasConsumerSupply` を追加した。液化石油ガス法上の一般消費者等への供給用充塡なら高圧ガス保安法第5条第1項第1号のかっこ書きによる適用除外候補（`other_law`）とし、該当性不明なら `invalid` とする。
- 許可境界未満の一般則・液石則は、`isBusiness: "yes"` のとき「事業開始の日の20日前まで」の届出、`no` のとき不要候補とする。事業性が未回答なら `invalid` とする。
- 冷凍は次の三分類を維持した。

  | 冷媒区分 | 許可 | 届出 |
  | --- | ---: | ---: |
  | 第一種ガス | 50t/日以上 | 20t/日以上 |
  | 不活性でないフルオロカーボン又はアンモニア | 50t/日以上 | 5t/日以上 |
  | 上記以外の冷媒ガス | 20t/日以上 | 3t/日以上 |

- 冷凍の第二種製造は「製造開始の日の20日前まで」と表示する。冷凍の届出判定に一般則の `isBusiness` を流用しない。
- 一般則・冷凍則・液石則の許可側には危害予防規程を残し、第二種製造の届出側からは除外した。法第26条は第一種製造者を対象とするためである。

### 2. 販売

- 原則は高圧ガス保安法第20条の4に基づく「事業開始の日の20日前まで」の届出とした。
- `smallSalesException` を追加し、政令第6条の対象ガスで、販売所の貯蔵数量が常時5m³未満であることを両方確認できた場合だけ不要候補とする。対象ガスまたは数量が不明なら `invalid` とし、不要にはしない。
- 政令第6条の対象は、医療用（大臣指定の種類を除く）、内容積300mL以下の容器内で35℃・20MPa以下のもの（大臣指定の種類を除く）、消火器内、内容積1.2L以下の容器内の液化フルオロカーボン、自動車又はその部分品内（大臣指定のものを除く）、大臣指定の緩衝装置内の高圧ガス（自動車内を除く）の6類型と設問ヘルプに明示した。`smallSalesException: "no"` の通知結果には、この確認済みの例外を再掲する古い注記を残さない。
- `selfSale` の質問を「法第5条第1項第1号の第一種製造者が、自ら製造したガスをその製造事業所内で販売する場合」に限定した。冷凍の第一種製造者（法第5条第1項第2号）はこの免除条件に含めない。
- 液化石油ガスについては `lpgasConsumer` を追加し、液化石油ガス法上の「一般消費者等」への供給は高圧ガス保安法の販売届出ではなく、液化石油ガス法側の登録等を確認する `other_law` とした。一般消費者等に該当するかは利用者に確認させ、推測しない。

### 3. 貯蔵

- 第一種製造者が製造許可の範囲内でその製造事業所に貯蔵する場合は、貯蔵所の許可・届出を不要候補とする既存の適用除外を維持した。
- 一般則の分類を、第一種ガスのみ（許可3,000m³）、第一種ガス以外のみ（許可1,000m³）、混合（一般則第103条の `N = 1000 + (2/3) × M`）に分けた。混合は300m³以上かつ許可基準未満を第二種貯蔵所の届出とする。
- 液石則の貯蔵は、供給設備・貯蔵施設が液化石油ガス法の対象かを `lpgasSupply` で確認し、該当時は `other_law` とした。該当しない場合は1,000m³の許可境界と300m³の届出境界を使う。
- 貯蔵所の許可・届出未満でも、一般則第19条第1項は法第15条ただし書の貯蔵容積を0.15m³とし、第2項は液化ガスの質量10kgを容積1m³とみなす。したがって少量除外の0.15m³相当は1.5kgであり、容器の物理的な内容積そのものではない。液石則第20条も0.15m³（液化ガスの状態では1.5kg）と明記する。結果注記はこの1.5kg相当に修正した。
- `storageThirdGas` を追加した。施行令第5条の第三種ガスを含む場合は、第一種ガス・それ以外の単純分類や混合算式を自動適用せず `invalid` とする。第三種ガスの有無が不明でも同じ扱いとする。

### 4. 消費

- 特殊高圧ガス7種は、従来の「容器利用／貯蔵なし」を理由とする誤った除外を削除した。`special7CalibrationOnly: "no"` なら、容器からの消費でも数量・濃度にかかわらず特定高圧ガス消費届出の対象候補とする。
- 経済産業省逐条解説が示す、漏えい検知警報設備の校正試験だけの用途だけを `yes` の限定例外とした。用途不明は `invalid` とする。校正試験でも消費・貯蔵・移動の技術基準は別途確認する注記を残した。
- 液化石油ガスは、液化石油ガス法上の一般消費者等なら `other_law` とし、それ以外では導管供給なら貯蔵能力にかかわらず届出候補とした。
- 販売・消費とも、液化石油ガス法上の一般消費者等の該当性を「不明」と回答できるようにし、不明時は後続の例外条件へ進めず `invalid` とした。
- 導管供給がない液化石油ガスは、`lpgasLargeConsumer` が `no` なら3,000kg、`yes`（液化石油ガス法施行令第2条各号の者）なら10,000kgを貯蔵能力境界に使う。不明は `invalid` とする。
- 水素・天然ガス300m³、液化酸素・アンモニア3,000kg、液化塩素1,000kgの既存の施行令第7条分類も維持した。

## 追加した設問

今回追加した判定上の設問IDは次のとおり。既存の関数インターフェースは変えていない。

| 設問ID | 対象 | 不明時 |
| --- | --- | --- |
| `smallSalesException` | 販売の政令第6条対象ガスかつ常時5m³未満か | `invalid` |
| `storageThirdGas` | 貯蔵に施行令第5条の第三種ガスを含むか | `invalid` |
| `special7CalibrationOnly` | 特殊高圧ガスが校正試験だけの用途か | `invalid` |
| `lpgasLargeConsumer` | 液石法施行令第2条各号の者で1万kg特例に該当するか | `invalid` |
| `lpgasConsumerSupply` | 液石則の製造が一般消費者等への供給用充塡か | `invalid` |

既存の `lpgasConsumer` も、一般消費者等の定義を説明するヘルプと「不明」選択肢を明示し、未確認時は `invalid` とするよう補強した。

## 未解決・手動確認が必要な条件

- 施行令第6条の販売届出例外は、対象ガスの種類と販売所ごとの「常時5m³未満」の事実確認が必要。今回の診断は利用者が両方を確認した場合だけ不要候補にする。
- 施行令第5条の第三種ガスを含む貯蔵は、混合組合せ・数量・設備条件をこの診断で自動分類していない。`invalid` のまま都道府県窓口への確認が必要。
- 液化石油ガス法上の「一般消費者等」および同法施行令第2条各号の該当性は、用途・供給形態・事業者の実態で確認が必要。文言だけから自動推定していない。
- 特殊高圧ガスの校正試験例外は経済産業省逐条解説に基づく限定的な扱いであり、校正試験以外の用途を含む場合の詳細な設備・技術基準、届出書類、移動・貯蔵は別途確認が必要。
- 技術上の基準、例示基準、基本通達、設備仕様、自治体の運用、他法令の許認可までは四行為の機械判定に取り込んでいない。最終的な該非と手続きは所在地の都道府県窓口で確認する。
- 法令・公式案内の改正確認は今回の確認日が基準。次回改正時は、上記のe-Gov条文と設問境界を再照合する。
