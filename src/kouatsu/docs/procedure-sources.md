## 法令原文による変更条件の照合

e-Gov API Version 2の現行本文（JSON）を読み取って確認した。公開URLは各規則本文にリンクする。

| 出典 | 条文・用途 |
| --- | --- |
| [一般高圧ガス保安規則](https://laws.e-gov.go.jp/law/341M50000400053) | 第15・17条（製造の軽微変更）、第28・30条（貯蔵の軽微変更）、第53・56条（消費明細・変更明細）、第57条（消費の軽微変更） |
| [液化石油ガス保安規則](https://laws.e-gov.go.jp/law/341M50000400052) | 第16・18条（製造）、第29・31条（貯蔵）、第51・54・55条（消費） |
| [冷凍保安規則](https://laws.e-gov.go.jp/law/341M50000400051) | 第17・19条（第一種／第二種の軽微変更の違い） |

冷凍の取替えは能力不変だけでは確定しない。可燃性・毒性冷媒、冷媒設備の切断・溶接、第一種での耐震設計対象設備を条件に含める。第二種の独立設備撤去では認定指定設備を除く点を質問に明示した。

一般則・液石則の取替えでは、特定設備／貯槽の除外、適切な製造者等の証明、能力不変を確認する。これらに該当しない工事にも別の軽微変更類型が存在するため、他の工事を自動的に変更許可と断定せず候補表示にする。認定事業者の特例を一般事業者へ拡張しない。

法上の変更許可・変更届が不要な場合でも、能力・ガス種類の変更では奈良県施行細則第13条第2項の報告を確認する。第一種の軽微変更届と県規則の報告は同じものとして統合しない。

## 実装上の保留を明示する事項

- 貯蔵・消費は県の公開ページに詳細な添付一覧がないため、規則の基本書類と、事前連絡の準備資料を区別する。
- 県の貯蔵完成検査ページの金額に不明瞭な表記がある。推測で金額を確定せず、奈良県手数料条例による区分・金額の確認を案内する。
- 官公庁の予約や検査調整など、正式に必要な連絡を省略できるとは案内しない。
- 検査周期・完成検査の除外、役職の選任要件や免除、特殊な認定制度は、案内だけで自動確定した扱いにしない。
