異体字(外字)作成ツール

画像から Windows 11 の外字(EUDC)を作成し、IME の変換候補として登録するための下ごしらえを行います。

Step 0. まず既存の文字で足りないか検索

独自の外字は他の環境では表示されません。まずは既存のUnicode文字やIVS(異体字シーケンス)で目的の字形が無いか検索し、見つからない場合だけカスタム外字の作成に進んでください。

書体ごとの字形

異体字・旧字体・互換漢字

この文字に対応する異体字は見つかりませんでした。

IVS異体字(このPCのフォントで表示できるもの)

「IVS異体字を検出」を押すと、お使いのPCのフォントで実際に表示できる異体字シーケンスを探します。

1. 画像を選択

クリック / ドラッグ&ドロップ / Ctrl+V で貼り付け

スニッピングツールで切り取ってそのまま Ctrl+V できます。

2. 調整

3. 登録先コードポイントを選択

登録先: U+E000

網掛けのセットは既に外字が登録されている可能性があります(お使いのPCの外字フォントで判定)。空いているコードを選んでください。

4. BMPを保存して外字エディターに貼り付け

モノクロBMPとして保存し、ペイントを経由して外字エディターに貼り付けます。

ブラウザから直接コピーして貼り付けると黒く潰れます。 ブラウザは32bitの画像しかクリップボードに置けず、外字エディターがそれを正しく解釈できないためです。 面倒でも、必ず一度ペイントで開いてからコピーし直してください。
  1. 上のボタンでBMPを保存する
  2. 保存したBMPをペイントで開く(右クリック→プログラムから開く→ペイント)
  3. Ctrl+A で全選択 → Ctrl+C でコピー
  4. Win+R で eudcedit と入力し外字エディターを開く
  5. 上で選んだコードポイント(U+E000)を選んで「OK」
  6. Ctrl+V で貼り付け、「編集」→「同じコードで保存」で保存する

5. IME辞書登録情報

登録される語句: —

IVS(異体字シーケンス)を含む語句は、MS-IMEのユーザー辞書が受け付けない場合があります。その際は基底文字のみで登録し、変換後にIVSを適用してください。

手順

  1. Step 0 で既存のUnicode文字・異体字・IVSを検索する。目的の字が見つかればそれを登録すればよく、外字を作る必要はない(外字はこのPCでしか表示されないため、使わずに済むならその方がよい)
  2. 画像を読み込んで調整し、登録先コードポイントを選ぶ
  3. モノクロBMPをダウンロードする
  4. 保存したBMPをペイントで開き、Ctrl+A → Ctrl+C でコピーする
  5. Win+R で eudcedit と入力して外字エディターを開き、選んだコードポイントを指定する
  6. Ctrl+V で貼り付け、「編集」→「同じコードで保存」で保存する
  7. スタートメニューの検索で「ユーザー辞書ツール」を開き、「ツール」→「テキストファイルからの登録」でダウンロードした辞書ファイル(gaiji-dict-XXXX.txt)を読み込む
  8. IMEを切り替えて登録した読みを入力し、変換候補に目的の文字が表示されることを確認する

補足1: 必ずペイントを経由してください。このページから直接コピーして外字エディターに貼り付けると黒く潰れます。ブラウザは32bitの画像しかクリップボードに置けず、外字エディターがそれを正しく解釈できないためで、ツール側では回避できません。

補足2: 貼り付けた字が小さい・大きい場合は、出力サイズを外字エディターの編集枠に合わせて調整してください(既定の64×64が標準です)。

補足3: 辞書ファイルの読み込みに失敗する場合は、メモ帳で開き直して文字コードをUTF-8またはANSIに変更して保存し直すと解決することがあります。
