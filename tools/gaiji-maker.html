異体字(外字)作成ツール

画像から Windows 11 の外字(EUDC)を作成し、IME の変換候補として登録するための下ごしらえを行います。すべてブラウザ内で処理し、通信は一切行いません。

Step 0. まず既存の文字/IVSで足りないか確認

独自の外字はこのパソコンにフォントを入れないと他の環境では正しく表示されません。まずは既にあるUnicode文字やIVS(異体字シーケンス)で目的の字形が見つからないか確認し、見つからない場合だけ以下でカスタム外字の作成に進んでください。

  • 変換候補の一覧やIMEの拡張候補表示に「IVS」「異体字」の項目が出ないか確認する
  • スタートメニューで「IMEパッド」を検索して開き、文字一覧でUnicode内の近い字形を探す

1. 画像を選択

クリックまたはドラッグ&ドロップで画像を選択

2. 調整

3. 貼り付け用画像

登録先コードポイント: U+E000

このブラウザではクリップボードへの画像コピーに対応していません。「画像をダウンロード」をご利用ください。

4. IME辞書登録情報

手順

  1. まず Step 0 で、既存のUnicode文字やIVSの異体字で足りないか確認する
  2. 上のツールで画像を調整し「画像をコピー」を押す(対応していないブラウザでは「画像をダウンロード」して保存する)
  3. Win+R またはスタートメニューの検索で「外字エディター」(eudcedit.exe)を開き、上に表示されているコードポイントを選択して Ctrl+V で貼り付け、保存する
  4. スタートメニューの検索で「ユーザー辞書ツール」を開き、「ツール」→「テキストファイルからの登録」でダウンロードした辞書ファイル(gaiji-dict-XXXX.txt)を読み込む
  5. IMEを切り替えて登録した読みを入力し、変換候補に作成した外字が表示されることを確認する

補足: 辞書ファイルの読み込みに失敗する場合は、メモ帳で開き直して文字コードをUTF-8またはANSIに変更して保存し直すと解決することがあります。
