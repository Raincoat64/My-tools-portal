異体字(外字)作成ツール

画像から Windows 11 の外字(EUDC)を作成し、IME の変換候補として登録するための下ごしらえを行います。すべてブラウザ内で処理し、通信は一切行いません。

Step 0. まず既存の文字で足りないか検索

独自の外字はこのパソコンにフォントを入れないと他の環境では表示されません。まずは既存のUnicode文字やIVS(異体字シーケンス)で目的の字形が無いか検索し、見つからない場合だけカスタム外字の作成に進んでください。

書体ごとの字形

異体字・旧字体・互換漢字

この文字に対応する異体字は見つかりませんでした。

IVS異体字(このPCのフォントで表示できるもの)

「IVS異体字を検出」を押すと、お使いのPCのフォントで実際に表示できる異体字シーケンスを探します。

1. 画像を選択

クリック / ドラッグ&ドロップ / Ctrl+V で貼り付け

スニッピングツールで切り取ってそのまま Ctrl+V できます。

2. 調整

外字エディターに貼り付けて黒く潰れる場合は、出力モードを「白背景」に切り替えるか、一度ペイントに貼り付けてからコピーし直して貼り付けてください。

3. 登録先コードポイントを選択

登録先: U+E000

網掛けのセットは既に外字が登録されている可能性があります(お使いのPCの外字フォントで判定)。空いているコードを選んでください。

4. 外字フォントを生成(推奨)

画像から輪郭を起こして外字フォント(EUDC.TTE)を直接作ります。クリップボードも外字エディターも使わないため、黒潰れは起きません。

既に外字を登録している場合は必ず読み込んでください。 読み込まずに生成すると、これまでの外字が入っていないフォントになります。既存ファイルは通常 C:\Windows\Fonts\EUDC.TTE にあります(差し替える前にコピーを取っておいてください)。

未選択(新規フォントとして生成します)

生成結果の確認(このブラウザで実際にフォントを読み込んで描画しています)

 
生成フォントでの表示

「ユーザー名」の部分はご自身のものに置き換えてください。管理者権限は不要です。

5. 補助: 画像として出力(外字エディターを使う場合)

外字エディターにクリップボード経由で貼り付けると黒く潰れます(ブラウザは32bit画像しかクリップボードに置けないため)。 外字エディターを使う場合は、モノクロBMPを保存 → ペイントで開く → Ctrl+A → Ctrl+C → 外字エディターで貼り付け、の順でお試しください。

このブラウザではクリップボードへの画像コピーに対応していません。

5. IME辞書登録情報

登録される語句: —

IVS(異体字シーケンス)を含む語句は、MS-IMEのユーザー辞書が受け付けない場合があります。その際は基底文字のみで登録し、変換後にIVSを適用してください。

手順

  1. Step 0 で既存のUnicode文字・異体字・IVSを検索する。目的の字が見つかればそれを登録すればよく、外字を作る必要はない
  2. 既に外字を登録している場合は、C:\Windows\Fonts\EUDC.TTE をコピーしてバックアップを取り、Step 4 の「既存の EUDC.TTE を読み込む」で読み込ませる(読み込まないと既存の外字が失われます)
  3. 画像を読み込んで調整し、登録先コードポイントを選ぶ
  4. 「外字フォントを生成」を押す。生成結果のプレビューで字形が正しいか確認したうえで、EUDC.TTE と .reg をダウンロードする
  5. EUDC.TTE を .reg に書いたパス(既定では ドキュメント フォルダ)に置き、.reg ファイルをダブルクリックして登録する
  6. サインアウト → サインインし直す(または再起動する)。メモ帳などで対象のコードポイントが表示されれば成功
  7. スタートメニューの検索で「ユーザー辞書ツール」を開き、「ツール」→「テキストファイルからの登録」でダウンロードした辞書ファイル(gaiji-dict-XXXX.txt)を読み込む
  8. IMEを切り替えて登録した読みを入力し、変換候補に目的の文字が表示されることを確認する

補足1: クリップボード経由で外字エディターに貼り付けると黒く潰れます。これはブラウザが32bit画像しかクリップボードに置けず、外字エディター側がそれを正しく解釈できないためで、ツール側では回避できません。上記のフォント生成の手順をご利用ください。

補足2: どうしても外字エディターを使いたい場合は、Step 5 でモノクロBMPを保存し、ペイントで開いて Ctrl+A → Ctrl+C でコピーしてから外字エディターに貼り付けてください。

補足3: 辞書ファイルの読み込みに失敗する場合は、メモ帳で開き直して文字コードをUTF-8またはANSIに変更して保存し直すと解決することがあります。
