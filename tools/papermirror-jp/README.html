ブラウザ版の使い方

  1. 文字を選択できる PDF を選び「PDF を解析」を押します。
  2. 原稿プレビューと読み順・翻訳範囲を確認し、チェックを付けて翻訳へ進みます。
  3. 翻訳パケットを Work・Claude・Gemini などの AI に渡します。
  4. 返された JSON を貼り付けるかファイルから読み込み、検証して保存します。複数バッチの場合はすべてのバッチを処理します。
  5. すべての翻訳を保存したら、日本語 PDF を生成します。機械検査に合格した結果を保存できます。

作業の保存と再開

作業はこのブラウザの IndexedDB に保存されます。24 時間を過ぎた作業は、ページが開いている間の定期確認または次回起動時に削除します。ブラウザを閉じたまま期限時刻ちょうどに削除する保証はありません。ブラウザのデータ削除や容量不足でも失われることがあります。

「作業ファイルを保存」で PDF と翻訳を一つのファイルに保存できます。別の端末や Work のブラウザでは「作業ファイルから再開」で読み込みます。原稿を再解析するため、読み順の確認はもう一度必要です。機械検査の PASS は読み込まず、PDF を再生成して検証します。

ページを開き直して完成済みの作業を選んだ場合も、原稿から再生成・再検査してから結果を表示します。保存された PASS だけでは検査を省略しません。

対応範囲

文字情報を持つ単段・2 段組の PDF が対象です。図、画像、罫線、リンク、参考文献の原文、ページの形状を保持し、変更を検査します。罫線で閉じた表のセルを検出します。原稿によって分類・読み順に誤りがあり得るため、解析結果を確認してください。

スキャン原稿、3 段以上、分離できない数式・上付き文字、縦書き、文字の重なり、低い可視性、フォームや能動的な内容、複雑な切替レイヤーなどは停止対象です。画像内に描かれた文字の翻訳は行いません。上限は 30 MB・100 ページで、画像・文字数などにも上限があります。端末のメモリによっては、上限内でも処理を完了できないことがあります。

日本語は固定の CJK フォントを埋め込みます。元の太字・斜体・字体の完全な再現は保証しません。領域に収まらない翻訳は省略せず、再試行を求めます。機械検査 PASS は翻訳の意味の正確さを保証しません。

PDF と翻訳データの扱い

PDF 処理はこのブラウザ内で行い、PDF をサイトのサーバーへアップロードする機能はありません。解析用 PDF・作業ファイル・出力 PDF は暗号化されていません。パスワードは保存しません。AI に渡す翻訳テキストはその AI サービスで扱われます。

Work のクラウドブラウザと手元のブラウザは別環境です。同じ URL を開いても作業データは共有されません。Work に PDF を渡して操作する場合、その PDF は Work のクラウド環境で扱われます。AI によるファイル投入・保存操作は各サービスの対応状況に依存します。
